# Kaitiaki Kreations

Dive into Ron Hairemy's world of pointillism.

**View the site:** https://theronhairemy-droid.github.io/kaitiaki-kreations/

Nine finished pointillism drawings — the anxieTREE trilogy, MANAIA, Whanaungatanga, and the beaver kiwi — presented as a single-page gallery. Hosted with GitHub Pages from the `main` branch.
